## 0. How to read this

### 0.2 Recommendation key

| Recommendation | Meaning |
|---|---|
| salvage | cherry-pick specific commits |
| reference | keep for ideas; re-implement on the new base |

**No item is recommended for salvage as code.** The reference items feed the plan's §6 list ("ideas only; no cherry-picks").

### 0.3 Columns and conventions

The columns follow brief Phase 0.2: last activity, position, files/packages touched, intent, completeness, builds?, salvageable, conflicts with the brief, recommendation, plus the archive tag that now protects the item.

- **Last activity:** commit date for commits; stash creation date for stashes (W commit); file mtime for uncommitted or ignored work (a rough signal only). Times are local to the commit (−0400 or −0500).
- **Position:** `behind / ahead` = `git rev-list --left-right --count origin/main...<ref>`. For a stash, the position is that of its **base** (`^1`); the stash's own W and I commits are on no branch. "Pushed?" means present on the remote today.
- **Never pushed:** no upstream, no remote-tracking ref, and (for the hex/arch3 tips) the GitHub API returns "No commit found".
- **Builds?:**
  - Earlier lanes (branch tips, live stashes, PRs): go1.24.0, `GOTOOLCHAIN=local`, either `-mod=mod` or the committed vendor tree with the ignored `.s` files overlaid.
  - The 26 newly assessed commits (P0.1 step 3): go1.27.2, `GOTOOLCHAIN=local`, `vendor/` removed, `-mod=mod`; `go build ./...` for linux/amd64 and darwin/arm64; `go vet ./...` for linux/amd64. The assessments checked that the builds left `go.mod`/`go.sum` unchanged.
  - **Every committed tree fails a default (`-mod=vendor`) build** from a clean checkout, because the allow-list `.gitignore` never committed the vendored `.s`/`.c`/`.h` files. "Builds" below therefore means "builds with modules". Maintainer decision 7 stops committing `vendor/`.
  - No hardn binary was executed for any of these assessments.
- **Landed / never-landed lines:** a stash or commit "landed" when a later commit has the same tree or patch-id, or when `git diff <item> <later>` over its files is empty. "N of M never landed" counts the item's non-trivial added lines that appear as an added line in **no** later commit on any branch or remote (for 777fa1a, re-counting with reflog-only commits included changed nothing).
- **Archive tags** (all local, created 2026-10-16, never pushed): 75 in total.
  - 8 branch tips: `archive/2025-03/<branch>` ×7 and `archive/2025-04/arch3`.
  - 37 live stashes: `archive/stash/<date>-<sha7>` (annotated with the original `stash@{n}` text and base).
  - 24 dropped stashes (W commits; their I commits are parents): `archive/dropped-stash/<date>-<sha7>`.
  - 5 reflog-only commits: `archive/reflog/<date>-<sha7>`.
  - 1 synthetic anchor for 50 dangling blobs and 28 dangling trees: `archive/dangling-objects/2026-10-16`.
  - After anchoring, `git fsck --unreachable --no-reflogs` reports nothing.
