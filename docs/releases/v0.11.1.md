# hardn v0.11.1

This release draws User Management's users in a frame with their last login, and fixes Create User's review when the password is set right after.

## Changed

- **User Management draws its users in a frame.** Each user's name is a badge with its last login beside it, such as "Nov 16 22:31 from 10.2.8.2", and a UID:GID row follows Password. The status row reads "User(s)". Alpine shows no last login: it keeps no record by default.

## Fixed

- **Create User's review says when the password is set next.** After yes to "Set deploy's password now?", it shows Sudo "Enabled", Password "Set next" and "Without a key, deploy logs in with its password". It said deploy had no password.
