# hardn v0.7.1

This release reorganises the documentation and adds the project's community files. What hardn does to a host is unchanged.

Not tested on real hosts: this release changes wording and documentation only.

## Changed

- **Menus and forms say "option" at every choice,** where prompts said "enter selection" or "enter your choice".
- **`hardn --version` names the licence:** a fifth line, `License:    GNU AGPL v3, no warranty`. install.sh says the same when it finishes.
- **The README is a third of its length.** Flags, exit statuses and output are in [docs/usage.md](../usage.md), refusals and the revert timer in [docs/safeguards.md](../safeguards.md), manual installs in [docs/install.md](../install.md), release checks in [docs/verify.md](../verify.md), each distribution's differences in [docs/platforms.md](../platforms.md), and the CVE check in [docs/cve.md](../cve.md).
- **The roadmap moved** to [docs/roadmap.md](../roadmap.md).

## New: community files

- **Help for schools, clinics and nonprofits,** in GitHub Discussions: [SUPPORT.md](../../.github/SUPPORT.md).
- **A mission,** and what hardn commits to and is not: [GOVERNANCE.md](../../.github/GOVERNANCE.md).
- **A code of conduct,** issue templates for bugs and feature requests, and a pull request template.
- **A contributor agreement** is asked before a first pull request is merged: [docs/contributing.md](../contributing.md#contributor-agreement).

## Security

- **Security reports by email go to `security@hardn.sh`.**
