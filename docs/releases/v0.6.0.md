# hardn v0.6.0

v0.6.0 supports Rocky Linux and AlmaLinux 10 and 9, with firewalld as the firewall and dnf-automatic for automatic updates.

## New: Rocky Linux and AlmaLinux 10 and 9

- **Users, sudo rules, SSH keys, root and password login, Environment and Backup** work as on Debian. sshd's configuration is checked with `sshd -t` over a copy, then `sshd.service` is reloaded.
- **Change SSH port** labels the new port for sshd in SELinux and lets it through each firewalld zone that carries SSH, before sshd moves. A rollback takes both back. Where SELinux is on, it needs semanage: `dnf install policycoreutils-python-utils` (`SELINUX_NO_SEMANAGE`).
- **The Firewall screen installs, enables and disables firewalld.**
  - Enable first lets each SSH port through the default zone, then is confirmed or rolled back like any change that could lock you out.
  - Install refuses a dnf install that would bring a new kernel (`PACKAGE_KERNEL`) or change installed packages (`PACKAGE_OTHER_CHANGES`).
  - It's refused beside ufw or another firewall (`FIREWALLD_OTHER_FIREWALL`).
  - Run All leaves the firewall to this screen; `-w` is refused (`FIREWALL_EL_READ_ONLY`).
- **Auto Updates turns on dnf-automatic's daily security updates.** It installs dnf-automatic where missing, sets `upgrade_type = security` and starts its install timer. Restarts stay as `automatic.conf` sets them (never, as shipped). Off undoes only what hardn did. Run All does it where hardn.yml's `enableUnattendedUpgrades` is true.
- **DNS is only read:** NetworkManager manages it there (`DNS_EL_READ_ONLY`).
- **Refused where SELinux enforces:**
  - an sshd file labelled otherwise than its policy (`SELINUX_MISLABELED`);
  - a hardn binary not labelled `bin_t` (`SELINUX_HARDN_NOT_RUNNABLE`), as one left in `/root`, or moved from `/tmp`, would be. systemd couldn't run it to roll a change back.
- **Refused where `/etc/sysconfig/sshd` sets `OPTIONS`** (`RELOAD_SYSCONFIG_OPTIONS`).

Tested on Rocky Linux 10.2 and 9.8 and AlmaLinux 10.2 and 9.8, on x86_64. Not yet on arm64. See the README's [Rocky Linux and AlmaLinux](https://github.com/abbott/hardn/blob/v0.6.0/README.md#rocky-linux-and-almalinux) section.

## Fixed

- **A command in hardn's text stays on one line,** so it copies as one: a fix such as `dnf install policycoreutils-python-utils`, and the countdown's `sudo hardn rollback <id>`.
- **Text no longer breaks after a hyphen,** inside a package name or a path.
- **A rollback starts an sshd that systemd is waiting to restart,** where the check after the reload used to fail on its state.
